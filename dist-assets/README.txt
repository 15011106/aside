aside — 설치 및 사용 안내
=========================

터미널에서 코딩 에이전트 작업처럼 보이는 화면으로 카카오톡 DM을 읽고 보내는
도구입니다. macOS 전용 (Apple Silicon / Intel 모두 지원, macOS 13 이상).


■ 설치 (3단계, 5분)
-------------------

[1단계] 압축 풀기
  받은 zip 파일을 더블클릭해서 압축을 풉니다.

[2단계] 설치 스크립트 실행
  터미널 앱을 엽니다 (Spotlight에서 "터미널" 검색).
  아래처럼 입력하되, 마지막에 공백 하나 치고 압축 푼 'aside' 폴더를
  터미널 창으로 드래그한 뒤 엔터:

      cd

  (예: cd /Users/이름/Downloads/aside)

  그 다음 아래를 입력하고 엔터:

      ./install.sh

  "설치 완료: ..." 메시지가 나오면 성공입니다.

[3단계] 접근성 권한 켜기  ← 이게 제일 중요합니다
  카카오톡 화면을 읽으려면 터미널에 권한이 필요합니다.

    시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용

  목록에서 "터미널"(또는 iTerm 등 본인이 쓰는 터미널 앱)을 찾아 켭니다.
  목록에 없으면 왼쪽 아래 + 버튼으로 직접 추가하세요.

  ★ 권한을 켠 뒤에는 터미널을 완전히 종료(Cmd+Q)했다가 다시 여세요.
    창만 닫으면 적용되지 않습니다.
  ★ 권한은 앱별로 따로입니다. iTerm에 권한을 줬으면 iTerm에서 실행하세요.


■ 실행
------

터미널에서 (어느 폴더에서든):

    aside

조작키
    ↑ / ↓      대화 이동
    /          이름으로 검색
    Enter      방 열기 / 메시지 전송
    Esc        뒤로 (열었던 방은 자동으로 닫힘)
    ?          단축키 도움말 토글
    Ctrl+Q     종료


■ 처음 실행 시
--------------

카카오톡이 꺼져 있으면 aside가 알아서 숨김 상태로 켭니다.
로그인 창이 뜨면 Dock에서 카카오톡을 눌러 한 번 로그인하세요.
("자동 로그인"을 켜두면 이후로는 신경 쓸 필요 없습니다.)


■ 문제가 생기면
---------------

먼저 이것부터 실행해 보세요:

    aside doctor

  accessibility trusted : true   → 권한 정상
                          false  → 3단계 권한 설정을 다시 확인 (Cmd+Q 후 재실행)

  kakaotalk running     : true   → 카카오톡 실행 중
  main window found     : true   → 대화 목록 접근 가능

전송이 안 될 때는 (메시지는 보내지지 않는 안전한 진단입니다):

    aside probe 방이름

  button found : true  → 정상
                 false → 개발자에게 이 결과를 알려주세요

그 밖의 명령
    aside ls        대화 목록만 보기 (읽음 처리 안 됨)
    aside version   버전 확인


■ 알아두실 점
-------------

- 카카오톡 공식 앱을 접근성 API로 조작합니다. 별도 서버 접속이나 프로토콜
  해킹이 아니며, 카카오 서버와 통신하는 것은 카카오톡 앱뿐입니다.
- 대화 내용은 저장하지 않습니다. 카카오톡 화면을 그때그때 읽을 뿐입니다.
- 방을 열면 카카오톡에서 그 방이 "읽음" 처리됩니다 (앱을 직접 열 때와 동일).
- 회사·학교 정책이나 기기 모니터링을 우회하는 도구가 아닙니다.
  사용 책임은 사용자 본인에게 있습니다.


■ 제거
------

    rm "$(which aside)"
